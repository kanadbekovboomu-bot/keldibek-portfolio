# 🌟 Келдибек Канатбеков — Frontend Developer Portfolio

Современный минималистичный веб-сайт портфолио начинающего Frontend-разработчика с плавной анимацией, вдохновлённый премиальным стилем [arunastudy-lemon.vercel.app](https://arunastudy-lemon.vercel.app/).

## ✨ Особенности
- 🌓 **Переключение темы**: Тёмная (Dark) и Светлая (Light) тема с сохранением выбора в `localStorage`
- 🌐 **Двуязычность**: Мгновенное переключение между Русским и Английским языком (RU / EN)
- 🚀 **Проекты с Live Demo и GitHub**:
  - **BilimKitep** (Образовательный проект)
  - **Monkeytype Clone** (React, Tailwind, Firebase, Vitest)
  - **Block Blast Game** (React, 8x8 Board, Polyominos, Firebase)
  - **Web Dev LMS Platform** (React, 15 уроков, DOM/CSS validator, Firebase)
  - **HTML/CSS/JS Code Editor** (React, Sandbox, Live Preview, Virtual Console)
  - **Коллекция 10 Vanilla JS проектов** (Калькулятор, Погода, Помодоро, Тест и др.)
- 🤼 **Спорт и характер**: Блок о вольной борьбе и спортивной дисциплине в программировании
- 💻 **Интерактивный терминал** в шапке с кодом конфигурации разработчика
- 🔍 **Фильтрация проектов**: по категориям (Все / React & Firebase / Образование / Игры и утилиты)
- 📱 **Полная адаптивность**: превосходное отображение от мобильных смартфонов до широкоформатных 4K экранов
- ⚡ **Плавный скролл, индикатор прогресса и кнопка «Наверх»**
